# Лабораторна робота 5, варіант 16. Моделювання плавучості тіла в рідині

Програма на C++ з графічним інтерфейсом SFML 3, залежність встановлюється через vcpkg (manifest-режим).

## Фізична модель
Тіло - прямокутний брус висотою H = 1 м і площею основи A = 1 м^2 - рухається вертикально на межі повітря і рідини
(поверхня рідини на y = 0, дно басейну на глибині 4 м). На тіло діють сила тяжіння m*g і сила Архімеда,
яка дорівнює вазі витісненої рідини: F = rho_l * g * A * h_зан, де h_зан - глибина занурення (від 0 до H).
Густина рідини стала, опір середовища не враховується.

## Математична модель
- m = rho_t * A * H
- a = (F_Арх - m*g) / m = (rho_l / rho_t) * g * (h_зан / H) - g
- v(t + dt) = v(t) + a * dt
- y(t + dt) = y(t) + v(t + dt) * dt (напівнеявний метод Ейлера)
- Рівновага: частка зануреної частини = rho_t / rho_l, якщо rho_t < rho_l (тіло плаває); якщо rho_t >= rho_l, тіло тоне.
- Параметри: g = 9.81 м/с^2; змінюються густина тіла rho_t та густина рідини rho_l.

## Структура
- Physics.hpp - модель (без залежності від SFML), метод step(dt)
- main.cpp - handleInput / updatePhysics / drawScene
- vcpkg.json - залежність sfml, CMakeLists.txt, CMakePresets.json

## Керування
- Пробіл - пауза / продовження
- R - перезапуск
- Стрілки Вгору / Вниз - густина тіла (крок 50 кг/м^3)
- Стрілки Вліво / Вправо - густина рідини (крок 100 кг/м^3)

## Експеримент 1. Густина тіла (рідина 1000 кг/м^3)
Тіло падає з висоти 1.5 м над водою, dt = 0.0005 с, усереднення зануреності за t > 10 с:

| rho_t, кг/м^3 | rho_t / rho_l | середня зануреність | теорія | результат |
|--------------:|--------------:|--------------------:|-------:|-----------|
| 300 | 0.30 | 31.5 % | 30 % | плаває |
| 500 | 0.50 | 51.2 % | 50 % | плаває |
| 800 | 0.80 | 82.3 % | 80 % | плаває |
| 950 | 0.95 | 96.1 % | 95 % | плаває |
| 1000 | 1.00 | - | - | тоне (нейтральна плавучість, рух за інерцією) |
| 1100 | 1.10 | - | - | тоне |
| 2000 | 2.00 | - | - | тоне |

## Експеримент 2. Густина рідини (тіло 600 кг/м^3)

| rho_l, кг/м^3 | rho_t / rho_l | середня зануреність | теорія | результат |
|--------------:|--------------:|--------------------:|-------:|-----------|
| 500 | 1.20 | - | - | тоне |
| 600 | 1.00 | - | - | тоне |
| 800 | 0.75 | 70.6 % | 75 % | плаває |
| 1000 | 0.60 | 59.2 % | 60 % | плаває |
| 1200 | 0.50 | 51.2 % | 50 % | плаває |
| 13600 | 0.044 | 4.4 % | 4.4 % | плаває |

Висновок: тіло плаває, коли його густина менша за густину рідини, і тоне, коли вона більша або дорівнює;
рівноважна зануреність дорівнює відношенню густин. Без опору плаваюче тіло коливається навколо цього положення.
